DOOM
ROGUE

Doom, but every run is a brand-new dungeon. One life.

12 procedurally generated floors, perks on every level-up, weapons that roll rarities, and a boss waiting at the bottom. Free, built on GZDoom and Freedoom.

WHAT IS IT

#

Fresh dungeons

Every run builds 12 new floors: rooms, corridors, doors, pillars, platforms and toxic pools. The exit sits in a locked vault; find the keycard first.

+

Perks

Kills give XP. Every level-up pauses the game and offers three perks. 13 perks, most stack. Build a vampire, a glass cannon, or a walking tank.

*

Loot rarities

Weapons roll Common to Legendary, with bonus damage, crits and lifesteal. Rare drops glow in their color.

!

Permadeath

One life. Die and the dungeon is gone, and the next run is a new one. Beat the Cyberdemon on floor 12 to win.

DOWNLOAD & INSTALL

Unzip, double-click, play. The first launch downloads the GZDoom engine and the free Freedoom assets (about 50 MB) into a data folder next to the game.

WINDOWS

Download .zip

  1. Unzip DoomRogue-windows.zip somewhere like Documents\DoomRogue.
  2. Double-click DoomRogue.exe.
  3. If Windows shows “Windows protected your PC”, click More info → Run anyway. The game isn't code-signed yet.
Windows 10 or 11, 64-bit. Nothing else to install.

MACOS

Download .zip

  1. Unzip DoomRogue-mac-linux.zip.
  2. Right-click DoomRogue.command → Open → Open. This is only needed the first time, because the file isn't signed.
  3. If macOS offers to install command line developer tools, accept. That installs Python. Then open it again.
Apple Silicon and Intel. Uses your GZDoom/UZDoom in Applications if you have one.

LINUX

Download .zip

  1. Install GZDoom or UZDoom (distro package or the official .deb).
  2. Unzip DoomRogue-mac-linux.zip.
  3. Run python3 doomrogue.py
Engine not on your PATH? Use --engine /path/to/gzdoom.

HOW TO PLAY

A run, start to finish

  • You start on Floor 1 with a pistol. Each floor is new for this run.
  • Find the keycard (red, blue or yellow). It opens the matching vault door around the glowing exit gate.
  • Step on the gate to go down a floor. Your weapons, ammo, perks and XP come with you.
  • Monsters get tougher every floor (+7% health each floor, and new types every few floors).
  • Floor 12 is a boss arena. The gate stays sealed until the Cyberdemon dies.
  • Die and the run is over. You'll see a summary, and the launcher offers a fresh dungeon.

Controls & screen

  • Default controls: WASD to move, mouse to aim, left click to shoot, E to open doors, Space to jump. Rebind them under Options → Customize Controls.
  • Level-up menu: 1 2 3, or arrows + Enter, or click a card.
  • The panel on the left shows your floor, level, XP bar, kills, perks and the rarity of your current weapon.
  • You can save mid-run. If you quit while alive, the launcher offers Resume. Dead runs' saves are deleted.
  • Replay a specific dungeon with --seed 1234. The seed is on the death screen. Difficulty: --skill 1–5.

LOOT

Every weapon you find rolls a rarity, and it glows in that color. Deeper floors and the Treasure Hunter perk roll better. Weapons dropped by monsters roll a bit worse.

RarityBonuses for that weapon
Commonnone
Uncommon+8–14% damage
Rare+15–25% damage, +4–7% crit
Epic+25–35% damage, +7–10% crit, 2–3% lifesteal
Legendary+40–55% damage, +10–14% crit, 3–5% lifesteal

Found a duplicate? You keep the best of each stat plus +3% damage. Monsters also drop ammo for weapons you own, plus health and armor bonuses.

FAQ & TROUBLESHOOTING

Windows says “Windows protected your PC”
The .exe isn't code-signed (signing certificates cost money). Click More info → Run anyway. Some antivirus tools also flag one-file Python executables by mistake. The game is built in the open by GitHub Actions from the source in the repository.
macOS says the file “cannot be opened”
Right-click DoomRogue.command → Open → Open. You only need to do this once. If it complains about python3, run xcode-select --install in Terminal and try again.
The game window opens and closes immediately
Open data/last_run.log next to the game and look at the last lines. On Windows, make sure your graphics drivers are up to date (GZDoom needs OpenGL 3.3 or Vulkan). Then open an issue on GitHub and attach that log.
Can I use the original Doom II instead of Freedoom?
Yes, if you own it: start with --iwad path/to/doom2.wad (from a terminal, or a shortcut with that argument).
Where are my saves and downloads? How do I uninstall?
Everything lives in the data folder next to the game: the engine, Freedoom, generated dungeons, saves and logs. To uninstall, delete the DoomRogue folder.
I found a bug / have an idea
Open an issue on GitHub. For bugs, include your OS, the seed (from the death screen) and data/last_run.log.
Does it work with UZDoom?
It's developed and tested on GZDoom 4.14. UZDoom (the GZDoom successor) uses the same scripting and should work. If you have it installed in Applications (macOS) or on your PATH, the launcher uses it automatically.

UNDER THE HOOD

  • dr_gen.py: the level generator. Pure Python, writes UDMF maps into a WAD.
  • mod/scripts/*.zs: ZScript for XP, perks, loot, HUD, menus and permadeath.
  • doomrogue.py: the launcher (seed → generate → play → repeat).
  • Every push is checked by CI. Each release tag builds the Windows .exe automatically.
