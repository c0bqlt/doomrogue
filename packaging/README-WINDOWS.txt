DoomRogue for Windows
=====================

1. Double-click DoomRogue.exe.
   - Windows may show "Windows protected your PC" because the game isn't
     code-signed. Click "More info", then "Run anyway".
2. The first launch downloads the GZDoom engine (~22 MB) and Freedoom
   (~24 MB, free Doom-compatible assets) into a "data" folder next to the exe.
3. Every run is a new 12-floor dungeon. One life. Have fun.

Keep DoomRogue.exe in its own folder (e.g. Documents\DoomRogue), not inside the zip.

Docs, perks list and troubleshooting: see the project page linked on GitHub.
Found a bug? Open an issue on GitHub and attach data\last_run.log.
